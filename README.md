# 🏖️ Туристический агент

Desktop-приложение для управления турами, отелями и бронированиями.

## Стек технологий
- Python 3.10+
- Tkinter (графический интерфейс)
- SQLite3 (база данных)
- hashlib (хеширование паролей)

## Как установить
1. Скачайте проект: `https://github.com/IvanNesterov4464/-2-1-11`
2. Или нажмите "Code" → "Download ZIP" и распакуйте
3. Убедитесь, что установлен Python 3.10+

## Как запустить
1. Откройте терминал в папке проекта
2. Выполните: `python app.py`
3. Войдите: логин `admin`, пароль `Admin123!`

## Возможные проблемы
- Если пишет "No module named tkinter" — переустановите Python с официального сайта
- Если не запускается — запускайте через терминал, чтобы увидеть ошибку
